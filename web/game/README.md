# Game Frontend

Reserved for the new frontend demo after the core game works from scripts or command-line input.

The demo will display the map, vessel state, mission metrics, and checkpoints. It will send direct heading and speed actions, pause/resume requests, and Copilot input to the runtime. Physical calculations and mission rules remain in `game/`.

The runtime connection and frontend framework will be selected when this phase starts. This directory does not contain a working application yet.

The existing `web/prototype/`, `web/map-spike/`, and `web/public/` remain available as reference experiments and exports.
